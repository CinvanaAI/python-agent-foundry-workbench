# Origin and lineage

The working tree was built between April and June 2026 as a handcrafted Python
continuation of many earlier Builder and Factory iterations. Internally it was
called “the real thing.” It became a major predecessor to the later
coding-agent-built Skeleton generation, which carried the capability-platform
and ownership questions into a different implementation rather than acting as a
file-for-file rewrite.

This public repository preserves the authored application source while treating generated artifacts as runtime evidence rather than distributable fixtures. Focused public repositories separately present the Foundry compiler, Assembly runtime, materialized task runner, chatroom ledger, and capability-graph importer so those mechanisms can be evaluated without navigating the entire desktop application.
